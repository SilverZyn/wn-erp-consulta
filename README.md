# WN Personalizados — Consulta

Site de consulta pelo celular da WN Personalizados (somente leitura). Mostra indicadores, pedidos, vendas e clientes a partir da nuvem do WN ERP, **somente após login** de uma conta convidada para a empresa.

Este repositório contém apenas o site já gerado. Ele não contém dados nem segredos; a única chave incluída é a chave **pública** do Supabase, que só dá acesso conforme as regras de acesso do banco.

Gerado a partir do código-fonte privado (commit `7a540e0`) com `pnpm celular:build`.
